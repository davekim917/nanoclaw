### B1 — `lintArtifact` + checks
- **Files:** `linter.ts` (CREATE), `linter.test.ts` (CREATE). **Test file:** `container/agent-runner/src/mcp-tools/design-review/linter.test.ts`.
- **Approach:** parse HTML with a Cheerio-style parser (verify availability before pinning — see Known Risks; if not present, use the runtime's built-in `HTMLRewriter`/DOMParser to avoid a new dep, per C6/supply-chain). Implement checks emitting `Finding{ id:`<check-key>:<locus>`, severity:'high'|'medium'|'low', locus, message }`.
- **Interface:** `export function lintArtifact(html: string, opts: LintOpts): Finding[]`
- **ASSERT (A8/token-trace):** a `color`/`background`/`px` literal used outside the `:root` block and not in the allowlist (`0`, `1px`, `100%`) → finding `token-trace:<selector>` severity high.
- **ASSERT (C8/no-JS):** ANY `<script>` (inline or external) → `no-js:<locus>` severity high; also `fetch`/`XMLHttpRequest`/`<img src=http…>`/`<link rel=preconnect>` beyond the font host → `network:<locus>` high.
- **ASSERT (font denylist):** a `font-family` naming {Inter,Roboto,Space Grotesk,Geist,Plus Jakarta Sans,Fraunces} without a DESIGN.md justification marker → `font-denylist:<locus>` medium.
- **ASSERT (states):** a data/interactive surface lacking an empty/error/loading affordance → `state-missing:<locus>` medium (high if primary surface).
- **ASSERT (branded-generic):** layout matching the slop-baseline skeleton → `taste-branded-generic:layout` medium.
- **Named tests:**
  - `test_hardcoded_hex_outside_root_flagged`: Setup: HTML with `color:#c0ffee` on `.x`, no matching `:root` token. Action: `lintArtifact`. Assert: a `token-trace:.x` high finding present. Teardown: none.
  - `test_inline_script_high`: Setup: HTML with `<script>1</script>`. Assert: `no-js` high finding.
  - `test_clean_good_fixture_passes`: Setup: read `fixtures/kanban-good.html`. Assert: zero high findings.
  - `test_slop_fixture_flags`: Setup: read `fixtures/kanban-slop.html`. Assert: ≥1 high or medium finding incl. a branded-generic or font-denylist hit.
- **Acceptance:** [ ] all 6 check families implemented; [ ] all named tests pass via `bun test`; [ ] container `bun run typecheck` clean.

### B2 — WCAG-AA contrast helper
- **Files:** `contrast.ts` (CREATE) + tests inline in `linter.test.ts`. **Test file:** (covered by `linter.test.ts`).
- **Approach:** compute relative-luminance contrast ratio for resolvable fg/bg token pairs; emit `contrast:<selector>` high when < 4.5:1 for normal text. Where a pair isn't statically resolvable, skip (no false high).
- **ASSERT:** a `#777` on `#fff` text pair → contrast high finding (ratio ≈ 4.48 < 4.5). A `#000` on `#fff` → no finding.
- **Acceptance:** [ ] contrast ratios match WCAG formula on 3 known pairs; [ ] no finding when unresolvable.

## Group C: design_review MCP tool + state machine

**Owns:** `design-review/{index.ts,state.ts,state.test.ts,render.ts}` + MODIFY barrel `mcp-tools/index.ts`. **Pre-conditions:** B complete (imports `lintArtifact`); A passed (render+register proven). **Interface to E:** the `design_review` tool contract below.

### C1 — `design_review` tool
- **Files:** `design-review/index.ts` (CREATE). **Test file:** `design-review/state.test.ts` (state covered in C2; tool wiring covered by integration in spike + C2).
- **Approach:** define the tool the same way `send_file`/`render_diagram` do (`registerTools([...])` at module scope; import in barrel). Input `{ artifactPath, designSystem, id }`. Orchestrates: load/rehydrate state (C2) → render (C3) → `lintArtifact` (B) → assemble findings → carry-forward diff → return `{ round, findings, mustFixOpen, status, screenshotPaths, tracePath }`. The **taste critic** is invoked by the SKILL.md loop (separate process), NOT inside this tool — the tool returns the screenshot paths + rubric for the critic; the tool records the critic's returned findings on the next call.
- **Tool contract:** `design_review({ artifactPath: string, designSystem: string, id: string, criticFindings?: Finding[] }) -> { round, findings: Finding[], mustFixOpen: Finding[], status: 'continue'|'blocked'|'shipped-with-disclosures', screenshotPaths: string[], tracePath: string }`
- **ASSERT (C7):** `round` never exceeds 3; at round 3 the tool returns `blocked` (any open high) or `shipped-with-disclosures` (else) — never `continue`.
- **ASSERT (C3):** the tool makes NO network/credentialed calls (no new egress; render is local chromium).
- **Acceptance:** [ ] tool registered + invocable; [ ] returns the contract shape; [ ] round cap + R9 status enforced; [ ] typecheck clean.

### C2 — Disk-atomic state machine
- **Files:** `state.ts` (CREATE), `state.test.ts` (CREATE). **Test file:** `design-review/state.test.ts`.
- **Approach:** state lives at `/workspace/agent/design-artifact-loop/<id>/trace.json`. `readState`/`writeState` use **write-temp-then-rename** (atomic) under an advisory `trace.lock` (flock or lockfile). Finding identity = `<check-key>:<locus>`; cross-round diff marks each as resolved/unresolved/new. Crash recovery: PNGs newer than last trace write → re-run the round's critic; orphan PNGs without a trace round are discarded.
- **ASSERT (F1):** state is read from disk every call — module-level memory is never the source of truth (so Codex per-query teardown can't desync).
- **ASSERT (concurrency):** two overlapping `writeState` on the same `<id>` do not corrupt `trace.json` (lock + atomic rename).
- **Named tests:**
  - `test_carry_forward_marks_unresolved`: Setup: trace with finding `font-denylist:.h1` round1. Action: round2 with same finding still present. Assert: marked unresolved, not duplicated.
  - `test_resolved_when_absent_next_round`: finding gone in round2 → state `resolved`.
  - `test_atomic_write_no_partial`: simulate write; assert no `.tmp` left and `trace.json` is valid JSON.
  - `test_cap3_blocks_on_open_high`: round3 with an open high → status `blocked`.
- **Acceptance:** [ ] all named tests pass; [ ] atomic+lock verified; [ ] crash-recovery branch covered.

### C3 — Render module (pinned env)
- **Files:** `render.ts` (CREATE). **Test file:** none — reason: exercised via spike A3 + C1 integration (chromium render not unit-testable in CI without a display; covered by the spike gate).
- **Approach:** wrap `agent-browser screenshot` (primary) / `chromium --headless --screenshot` (fallback, mirroring `render-diagram.ts`) at 1440×900 + 390×844. Compute blank (PNG <2KB or >98% one-color) and overflow (`scrollWidth > vw+2`) → high findings.
- **ASSERT (C2):** renders both pinned viewports; emits `render-blank:<vp>` / `overflow:<vp>` high on failure.
- **Acceptance:** [ ] both viewports rendered; [ ] blank/overflow thresholds enforced; [ ] uses image-pinned chromium.
