# Legacy Specification Status

Everything under `.context/specs/` is archived historical evidence, not an
operator runbook or current-runtime contract. Old `APPROVED`, `READY`,
`SHIPPED`, and workflow-pause labels describe the state at the time they were
recorded.

Current source, tests, operator skills, and the top-level documentation indexed
from `AGENTS.md` are authoritative. Retired Mnemon, Ollama, memory-daemon,
provider-native auto-memory, and per-agent memory-store designs must not be
executed. The current memory contract lives in
`docs/specs/workgroup-memory-and-session-capabilities/design.md` and
`docs/memory.md`.
