# Observatory / Signal design system

Approved direction: `/home/ubuntu/design-artifacts/observatory-signal/artifact.html` and the `2addd684014a` desktop/mobile captures. The application adapts that composition to real variable-length records and working controls.

Canvas `#101112`; surface `#191b1d`; raised `#222527`; divider `#34383b`; text `#eef0f2`; secondary `#adb4bb`; primary action `#e8ece4`; attention `#efc181`. Mint is reserved for evidenced operational state. No purple, gradients, decorative glow or fabricated progress percentages.

Locally bundled Geist Variable carries prose. Geist Mono carries source hashes and code identities. Essential prose is 14–16px, metadata 12px, page title 30px and decision title 24px. Controls use 6px radii; the decision pane uses 12px. Focus outlines remain visible. Reduced-motion preference disables the refresh rotation.

Desktop: 184px rail, compact header, restrained content gutters, a 240–320px decision queue and a wide focused decision workspace. Agent and thread screens use a compact selector beside the selected work canvas. The approved open-aperture symbol identifies Observatory. Navigation includes Overview, Projects, Decisions, Agents, Threads and Schedule. Workspace selection and search are real controls.

At 850px the rail becomes a compact header with a six-link wrapping navigation grid. The decision queue is bounded to 270px above its selected context. Agent and conversation selectors are similarly bounded. Source IDs and variable prose wrap, forms fill their available width, and evidence has a bounded inner reading area. Page overflow is not used to conceal layout defects.

The default thread surface is a work brief with objective, current state, related decisions and progressive source evidence. A recent-conversation tab and explicit Full conversation mode expose transcript detail. The existing complete console remains a secondary operational surface and receives Signal palette/type tokens. The historical console stylesheet remains scoped for regression compatibility; the active shell owns the shipped palette.

Distinct state treatments: neutral loading/empty; amber source-health and connection notices; explicit refresh failure with retained records; exact-context failure pauses decisions; ownership conflicts request fresh context. Record-answer and send-instruction controls are separate. Approval records expose their original destination and never borrow a generic action button.
