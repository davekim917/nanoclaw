## Overview

Implements the cycle-3-simplified design:
- Migration 036 adds `workgroups` table + nullable `agent_groups.workgroup_id`; backfill auto-pairs `<x>-codex` siblings with parent `<x>`; preserves existing mnemon stores via `mnemon_store_id` = parent's `agent_groups.id`.
- Per-agent projection widens ONLY `messages_archive` to the workgroup (with dedup); `backlog_items`, `ship_log`, `tasks`, `agent_group_capabilities` stay agent-scoped.
- Scope-resolver splits into `resolveWorkgroupMembers` (members list) and `resolveWorkgroupStoreId` (single canonical store).
- Container-side `thread-search.ts` drops in-tool `WHERE agent_group_id = ?` filters (projection bounds visibility); `backlog.ts` and `server.ts` keep their filters.
- Spawn path reads `workgroups.mnemon_store_id` for `MNEMON_STORE` env; existing `MNEMON_STORE_<folder>` env override (PR #105) stays in place per C6.
- OneCLI secrets: workgroup baseline ∪ per-group additive at spawn time.
- FS reconciler runs once at startup (outside migration barrel) to write container.json `recall_scope` for paired groups + log files.
- Operator CLI `scripts/set-workgroup-secrets.ts` populates `workgroups.onecli_secrets` (otherwise feature ships dormant).

**5 groups, 21 tasks. Group A is foundational; Groups B/D/E run parallel after A; Group C runs after B.**
