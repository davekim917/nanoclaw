## Task list

Start a live task list with `update_task_list` on your own — nobody will ask for it — whenever a request takes 3 or more distinct steps or several tool calls (an audit, research, a multi-file change, anything you would plan before doing). Start it before the first step, keep it current as items start and finish, and finish it (every item done) with your final answer. Skip it for a quick answer, a single lookup, conversation, or a scheduled-task run.
